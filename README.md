# Souhil Sid — Portfolio Website

A static, host-ready, games-first portfolio for game development, digital twins, XR, phygital experiences and engineering simulation.

## Preview locally

Open `index.html` directly, or run a tiny local server:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Hosting

This site has no build step and can be deployed as-is to:

- GitHub Pages
- Netlify (drag the folder into Netlify Drop)
- Vercel (static deployment)
- Cloudflare Pages
- Any normal web host

## Before going public

1. Confirm every Google Drive demo link is shared as **Anyone with the link → Viewer**, or replace Drive links with YouTube/Vimeo links.
2. Replace/add a custom domain when ready (for example `souhilsid.com`).
3. Add analytics only if you want them.
4. The included CV is the latest file used while building this version; replace `assets/docs/Souhil-Sid-CV.pdf` anytime without changing the HTML.
5. Project thumbnails were extracted from the supplied project videos; keep them in `assets/images/` when deploying.

## Portfolio structure

- Games-first founder positioning
- Develop Together Corp origin story
- Scroll-driven horizontal game showcase
- Large-format achievements
- Six featured case studies
- Expertise pillars and filterable archive
- Working process
- About / CV and contact

## Design strategy

The story starts with Souhil as a **game-team founder**, then shows the progression from game systems into serious games, digital twins, XR and phygital engineering. The palette is based on Color Hunt's `#F5EEDC / #27548A / #183B4E / #DDA853` combination. Desktop uses a pinned horizontal game sequence; mobile switches to native horizontal snap scrolling.
